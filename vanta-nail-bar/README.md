# Vanta Nail Bar — Website Redesign

A clean, presentable redesign of [vantanailbar.com](https://vantanailbar.com/) as a static multi-page site.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Full service menu
- `gallery.html` — Image gallery with lightbox
- `contact.html` — Contact details, map, and form
- `privacy.html` — Privacy policy summary

## Standout improvements

- Full-bleed branded hero with live open/closed status (Dallas / America/Chicago hours)
- Streamlined service browsing with category tabs and expandable menu details
- Keyboard-friendly gallery lightbox
- Sticky mobile Book Now bar + existing online booking link
- LocalBusiness / NailSalon structured data on the home page
- Faster static HTML/CSS/JS (no page builder overhead)

## Preview locally

```bash
cd vanta-nail-bar
python3 -m http.server 8080
```

Open `http://localhost:8080`.
